# mpvEx-private

Private clean rebuild repository based on `marlboro-advance/mpvEx`.

This repo contains:

- mpvEx UI shell
- Beta3-derived localization resources
- AVC-fixed mpv AAR
- arm64-only unsigned build workflow
- repo and version documentation

OpenList is not built in. See `docs/OPENLIST.md`.

Do not delete `app/libs/mpv-android-avcfix.aar` or the private source repo `Tom0324/mpv-android-fongmi`.
